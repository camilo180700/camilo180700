## 💼 Real-World Projects

### ✅ QA2 – Automated Ad Implementation QA
Tool that validates that ad placements configured in the ad server match the requirements of the Traffic Sheet (the source of truth) **before launch**.
- Classifies each check as `PASS`, `FAIL`, `REVIEW` or `NOT_VERIFIABLE`
- Assigns severity (`CRITICAL` → `LOW`) to catch tracking, attribution and serving issues early
- Rule-based engine with parsers, CLI and a Streamlit UI

**Tech:** Python, Streamlit
🔗 Repository: https://github.com/camilo180700/QA_2
